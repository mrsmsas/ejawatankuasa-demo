# Demo Sistem eJawatankuasa

Demo untuk MRSM: sistem pengurusan jawatankuasa, pelantikan staf dan analisis beban kerja berasaskan merit.

Buka demo: https://mrsmsas.github.io/ejawatankuasa-demo/

Semua nama, emel, ID dan maklumat maktab dalam demo ini ialah **data rekaan**. Demo berjalan sepenuhnya dalam pelayar dan tidak bersambung ke mana-mana pangkalan data. Perubahan hanya disimpan dalam pelayar anda, dan butang **Set semula** memulangkan data asal demo.

Akaun demo boleh dipilih terus di halaman log masuk.
